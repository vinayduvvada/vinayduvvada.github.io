Overview

Custom Search Shortcuts is a Chrome extension built to eliminate the copy-paste-search cycle. Highlight any text on any webpage, right-click, and instantly search it across Google, GitHub, ChatGPT, Stack Overflow, or any custom URL you define — all in one click.


Built with Chrome Extension Manifest V3 and zero external dependencies — just clean, lightweight vanilla JavaScript. It supports unlimited custom search URLs, environment-aware variable substitution with {{variable}} syntax, drag-and-drop reordering, keyboard shortcut assignment, omnibox integration, dark/light/system theming, and a Gmail-style undo-delete trash bin.

Features

Core Search Engine

Unlimited custom search URLs, environment variables, dynamic {{variable}} URL templates, and seamless right-click integration.

Organization

Categories with emoji icons, nested context-menu submenus, drag-and-drop reordering for URLs, categories, and environments.

Favorites

Pin shortcuts to the top of the context menu and popup. Toggle favorites inline. Favorited URLs remain inside their category submenus too.

Keyboard Shortcuts

Assign custom hotkeys (e.g. Ctrl+Shift+G) to any search URL. Inline recorder with live modifier key feedback and purple dot badge indicator.

Omnibox Search

Type cs + Tab in Chrome's address bar, then a shortcut name and query. Auto-suggestions with exact → prefix → contains matching.

Environments

Define variables bound to Dev/Staging/Prod values. Right-click → pick environment → opens the correct target automatically.

Trash & Undo

Gmail-style delete with instant undo toast. Configurable retention (1–90 days). Restore individual items or empty all trash with one click.

Import / Export

Back up your entire config — URLs, categories, variables, environments, favorites, keyboard shortcuts, and settings — as a single JSON file.

Theming

Light, Dark, and System theme modes. Synced instantly between the popup and options page. Works on any OS without flickering.

How It Works

1

Install the Extension

Load unpacked from chrome://extensions/ in Developer Mode, or install from the Chrome Web Store (coming soon).

2

Add Your Search Engines

Open Options, enter a name and URL with %s as the search placeholder. Example: https://github.com/search?q=%s. Assign a category and optional emoji icon.

3

Select & Right-Click

Highlight any text on any webpage → right-click → Custom Search → select your engine. A new tab opens with your results instantly.

4

Advanced: Environment Variables

Define a variable like api_host with per-environment values, then use it in a URL: https://{{api_host}}/docs?q=%s. Choose Dev or Prod from the context submenu.

5

Omnibox Power Mode

Type cs in Chrome's address bar, press Tab, then a shortcut name and your query. Example: cs mdn flexbox.

Chrome Permissions

contextMenus
Create and manage right-click context menu items and nested category submenus.
storage
Save user configurations via chrome.storage.sync — synced across all signed-in Chrome devices. No external servers.
activeTab
Access current tab info for "Add Current Page" functionality and configurable tab positioning.
tabs
Query tab index so new search results open right next to your current tab (configurable).
scripting
Required for content script injection to enable global keyboard shortcut capture on all pages.
